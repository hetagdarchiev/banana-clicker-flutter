# Banana Bay — тропический Flutter-кликер

Банан вместо молнии, светлая жёлто-зелёная палитра, бирюзовое море,
движущиеся волны, покачивающиеся пальмы и летящие очки урожая.
Векторная графика нарисована Flutter: дополнительные изображения не нужны.
Механика кликов, комбо, покупки, достижения и автосохранение сохранены.
Ключи сохранения NOVA оставлены для переноса прогресса в том же приложении.



## Локальный запуск с актуальным stable Flutter SDK

В папке с pubspec.yaml:

```sh
flutter create --platforms=android,ios,web --project-name statefulclickcounter .
flutter pub get
flutter run -d chrome
```

Не используй --overwrite. Если генератор создаст стандартный test/widget_test.dart,
он относится к шаблонному счётчику: удали этот демонстрационный тест.

## Проверка

```sh
dart format lib test
flutter analyze
flutter test test/game_test.dart
```

В среде подготовки нет Flutter/Dart SDK: выполнена только статическая проверка
комплекта файлов и баланса скобок, сборка и визуальная проверка Flutter не выполнялись.

Автодобыча идёт при активном приложении. Сохранение выполняется каждые 2 секунды,
при покупке и уходе в фон. При резком закрытии возможна потеря последних 2 секунд.
